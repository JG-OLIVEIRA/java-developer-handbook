## Qual a diferença entre JDK, JRE e JVM?

### JDK - JAVA DEVELOPMENT KIT
O Kit de Desenvolvimento do Java (JDK) é um conjunto completo de ferramentas que inclui o JRE, além de ferramentas de desenvolvimento como compiladores, depuradores e documentação. O JDK é necessário para criar aplicações Java.

### JRE - JAVA RUNTIME ENVIRONMENT
Ambiente de execução do Java (JRE) é um conjunto de ferramentas que permite executar programas Java. Ele inclui a JVM, bibliotecas de classes e outros componentes necessários para rodar aplicações Java. O JRE não contém ferramentas de desenvolvimento, como compiladores ou depuradores.

### JVM - JAVA VIRTUAL MACHINE
A Máquina Virtual do Java (JVM) é um componente do JRE que executa o código bytecode gerado pelo compilador do Java. A JVM é responsável por carregar, verificar e executar os arquivos .class.
